This is Allodium's canonical dogfood discussion.

Its authoritative title, body, state, and project-owned identity live here in ordinary files. A GitHub Discussion may be projected from this object when the configured remote supports Discussions and the explicit provider category binding can be resolved.

GitHub comments, replies, answers, reactions, votes, locks, authorship, category taxonomy, node IDs, numbers, and URLs remain provider-scoped state unless a future canonical schema deliberately adopts some subset.

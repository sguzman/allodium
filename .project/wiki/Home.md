# Allodium

Allodium keeps operational project state in ordinary files owned by the user and projects that state onto external collaboration systems.

The canonical wiki is this directory. GitHub Wiki support will be a projection of these files, not their owner.

## Principles

- filesystem-native authority;
- explicit schemas;
- GitHub-first projection without GitHub ownership;
- remote-specific ingress with preserved provenance;
- explicit promotion into canonical state;
- reconstructible adapter bookkeeping.
